# Free Fire Top-Up Website Nepal 🔥💎

A modern, responsive website for Free Fire diamond top-up services in Nepal with Nepali Rupee (NPR) pricing and local payment methods.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Package Selection**: Click to select diamond packages with visual feedback
- **Real-time Form Validation**: Instant validation for email and player ID
- **Order Summary**: Live preview of selected package and total price
- **Success Modal**: Confirmation dialog after successful purchase
- **Smooth Animations**: Engaging hover effects and transitions
- **Modern UI**: Gradient backgrounds and glassmorphism effects

## Diamond Packages (NPR Pricing)

## How to Run

### Using Node.js

1. Make sure you have Node.js installed
2. Navigate to the project directory
3. Run the server:
   ```bash
   node server.js
   ```
4. Open your browser and visit: `http://localhost:3000`

### Direct File Access

Simply open `index.html` in your web browser.
